Jasprit Bumrah Cricket Performance Analysis

Overview

This project analyzes the cricketing performance of Jasprit Bumrah across different formats (Test, ODI, T20I) and oppositions. It leverages Python, Pandas, Seaborn, Matplotlib, and Plotly to generate insightful visualizations on his wicket-taking ability, economy rate, and bowling average.

Features

Format-Wise Analysis

Wickets taken

Economy rate

Bowling average

Opposition-Wise Analysis

Wickets taken against each team

Economy rate per opposition

Bowling average per opposition

Improved Visualizations

Color differentiation using Seaborn palettes (tab20c, tab20b, Set2)

Bar plots for easier comparison

Readable and aesthetically pleasing graphs

Technologies Used

Python 3.x

Pandas for data manipulation

Seaborn & Matplotlib for visualization

Plotly for interactive graphs

Installation

Clone the repository:

git clone https://github.com/your-repo/bumrah-analysis.git
cd bumrah-analysis

Install required dependencies:

pip install pandas seaborn matplotlib plotly

Usage

Run the Python script to generate the visualizations:

python bumrah_analysis.py

The script will output:

Format-wise analysis graphs

Opposition-wise performance graphs

Overall insights on Bumrah's career statistics
